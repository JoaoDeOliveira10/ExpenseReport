Click Add / Update Files in the File Management section or use the Actions section in the sidebar. You can select all your files at once — no limit.

You can also drag and drop files directly onto the dotted area. Files are saved automatically in the browser — next time you open the app, they are already there without needing to reload.

✓ Accepted formats: .xlsx, .xls, .csv
✓ Multiple files at once, no limit
✓ Data is persistent: available every time you reopen
✓ You can add, update or delete files at any time

Type the number or value you want to find in the search bar and press Search or Enter. The search runs across all columns, all sheets, and all loaded files.

Smart numeric search: se cerchi 86588, trova anche celle che contengono 86588.0 o 86,588 — il formato numerico non influenza il risultato.

ℹ️ Leave options unchecked for a broad search. Use Exact match only if you want to find exactly that number with no partial variants.

After each search, the Scan complete panel appears showing exactly how many rows were scanned, across how many files and sheets. Compare the total with what you know to ensure nothing was missed.

💡 Tips & Best Practices
🔄 Updating a file

To update an already loaded file, load it again with the same name. The app replaces it automatically with no duplicates.

🔢 Numbers with decimals

Search for the integer only (e.g. 86588) — the app automatically finds 86588.0 and 86,588 too.

🗑️ Removing files

In the File Management section, click the Remove button next to the file you want to delete. Or use Clear All to start fresh.

💾 Persistent storage

Files are stored in the browser using IndexedDB — no size limit, no external server. Data persists even after closing the browser.

🔒
Privacy & Security

All data is processed locally in your browser. No file and no data is transmitted to external servers. Data stays on your device, in the browser's local storage, and can be deleted at any time using the Clear All Saved Files button.
